# Documentation templates

Starting structures for an approved proposal—not a universal checklist. An
unfilled template is not evidence of maturity.

| Template                                               | Use when                                          |
| ------------------------------------------------------ | ------------------------------------------------- |
| [`README.template.md`](README.template.md)             | Every repository; trim to level                   |
| [`INSTALL.template.md`](INSTALL.template.md)           | Multiple paths or non-trivial setup               |
| [`architecture.template.md`](architecture.template.md) | A diagram improves the mental model               |
| [`adr.template.md`](adr.template.md)                   | A real decision has alternatives and consequences |
| [`audit.template.md`](audit.template.md)               | Recording the assessment                          |
| [`proposal.template.md`](proposal.template.md)         | Seeking approval for the after-state              |

Delete unused headings and bracketed prompts. Link generated or canonical
reference instead of copying it.
